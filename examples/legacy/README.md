# Legacy experiments

This directory retains unsupported historical experiments that are not part of
the installed SanPy package or desktop application. The files may depend on
removed modules, machine-specific paths, or obsolete APIs and are preserved for
reference rather than as runnable examples.

`bAnalysisStim.py` and the `run()` workflow in `fftUtils.py` depend on the
removed `stimGen2` experiment and are intentionally not maintained as runtime
features.
